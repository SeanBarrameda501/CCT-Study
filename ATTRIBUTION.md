## Generated ECG images (`images/generated/`) — labeled **GENERATED** in the app

Every file in `images/generated/` is a synthetic tracing created by this project's own code (`js/ecg.js`, built by `tools/build-strips.mjs`). They are not recordings of any person. Each one is automatically checked against textbook criteria (`tools/criteria.mjs`) before it is used. They are released with the rest of this project.

## Other graphics

The lead-placement diagrams and icons are drawn by this project in SVG.
